# ルーレット

入力した候補やチャット参加者から一つを抽選し、ルーレットとしてOBSへ表示します。

## OBSへ追加する

管理画面の「配信ソフトに追加する」から表示用アセットをOBSへ追加します。

ルーレットは正方形で表示されるため、OBS上では縦横比を維持して配置してください。

## 手動でエントリーする

「エントリー」の追加ボタンから候補を追加し、それぞれの名前を入力します。

不要な候補は個別に削除できます。「クリア」ですべての候補を削除します。

## チャットから募集する

1. 参加キーワードを入力します
2. 「募集を開始」を押します
3. 視聴者がキーワードを含むメッセージを投稿します
4. 投稿者がエントリーへ追加されます
5. 「募集を終了」を押して抽選を開始します
