# アプリ一覧

## 配信喫茶

![Omucafe](/img/omucafe.png)

雑談のお供にあなただけのカフェを開店しましょう！

[配信喫茶](%DOCS_ROOT%/app/omucafe)

## Discordオーバーレイ

![Discord Overlay](/img/discord-overlay.png)

- 安定して表示できるDiscordオーバーレイ
- DiscordのボイスチャットをOBSに表示することができます
- PNGTuber+アバターに対応。あなたの持っているPNGTuber+アバターでコラボ配信ができます

[Discordオーバーレイ](%DOCS_ROOT%/app/discord-overlay)

## リアクション

- Youtubeのリアクションボタンで出る効果を好きなように出すことができます
- 画像を置き換えることができます

[リアクション](%DOCS_ROOT%/app/reaction)

## リプレイ

- 過去にした配信やYoutubeの動画を流すことができます
- OBS側ではモザイクをかけたり、時間などの情報を表示できるので同時視聴にぴったりです
- 音をOBSとアプリの別々で管理することができます

[リプレイ](%DOCS_ROOT%/app/replay)

## ルーレット

- 手動で追加するほか、特定のキーワードを設定して募集してコメントでエントリーして抽選することもできます

[ルーレット](%DOCS_ROOT%/app/roulette)
