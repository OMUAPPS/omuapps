# 配信喫茶

雑談のお供にあなただけのカフェを営業しましょう

![omucafe](/img/omucafe.png)

## 遊び方

グッズをアイテムとして追加してコラボカフェ風にしたり、おしゃれなドリンクを提供してバーのように雰囲気を作り出したり…と想像力次第でいろいろなことができます！
